# Parallel Programming Labs

Лабораторные работы по дисциплине «Параллельное программирование».

В репозитории представлены последовательные и параллельные реализации вычислительных задач, а также результаты их тестирования и проверки корректности.

## О репозитории

Цель лабораторных работ — изучение последовательных и параллельных способов выполнения вычислительных задач и сравнение их производительности.

В первой лабораторной работе реализована последовательная версия алгоритма умножения матриц. Результаты её выполнения используются как основа для дальнейшего сравнения с параллельными реализациями.

Для каждой лабораторной работы используются одинаковые исходные данные и выполняется автоматическая проверка корректности полученного результата.

Подробные результаты экспериментов, таблицы замеров и графики находятся в соответствующей лабораторной работе.

## Структура репозитория

```text
parallel-programming-labs/
├── lab1/                  # последовательная версия
│   ├── input/             # исходные матрицы
│   ├── output/            # результат вычислений
│   ├── c++/               # исходный код C++
│   ├── generate.py        # генерация тестовых данных
│   ├── verify.py          # автоматическая проверка результата
│   ├── performance.png    # график производительности
│   └── README.md          # описание лабораторной работы
│
└── lab2/                  # следующая лабораторная работа
```
